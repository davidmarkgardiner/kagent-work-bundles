The problem

Connect the security facts
we currently inspect separately

Our controls today

Permissions and traffic controls

  • RBAC and workload identity define access.
  • Network and gateway policies restrict traffic.
  • Kyverno checks admitted resources.
  • Argo and Flux execute reviewed changes.
AgentShield adds

A graph with evidence

  • Which workload uses which identity?
  • Which policies govern the destination?
  • What path or policy changed?
  • What observation supports the finding?

Expected benefit: less manual correlation before the security specialist can explain a finding. Measure this in the PoC.

03 / 13 · Where it fits
PreviousNext

Inside the product

Observation becomes a
traceable security finding

  1. ObservePlugins collect Kubernetes configuration and supported telemetry.
  2. JoinStable resource identities connect workloads, policies, identities, and traffic in PostgreSQL.
  3. DetectRules examine graph changes. Model features must be enabled to start detection in the current service.
  4. InvestigateA model queries bounded graph context. Promotion requires evidence the graph actually returned.
  5. ProposeA finding can include a fix. Our PoC hands the proposal to external human review and GitOps.

A declared policy is intent. Effective enforcement still needs real traffic tests.

The first useful demonstration

A reporting agent reaches
a dummy secrets service

01

Baseline

A narrow-role reporting workload calls its approved report API. The collector records that traffic.

02

Unexpected request

A test action makes the same workload call a dummy sensitive service with fabricated data.

03

Evidence

AgentShield relates the observed path to workload identity and governing policy. A finding cites those observations.

04

Response

kagent explains the finding and proposes a policy diff. Approved delivery blocks the test path and preserves report traffic.

Pair the attack with a benign control, such as an authorized rotation controller calling the same service.

06 / 13 · Current support and gaps
PreviousNext

Deployment footprint

One observer.
One dedicated database.

AgentShield namespace

  • Build a container from pinned source.
  • Install the upstream Helm chart with one replica.
  • Use a dedicated PostgreSQL 16 database.
  • Keep cluster and source IDs stable across plugins.
  • Retain read-only Kubernetes permissions.

Access and data controls

  • The API has no built-in authentication.
  • Restrict API and collector access with verified network controls.
  • The default role can read every Secret. Values are discarded before storage.
  • ConfigMap and literal Pod environment data can persist.
  • Use dummy data for the initial cluster.

The stock chart starts inventory only. Setting a model endpoint alone does not turn on detection.

09 / 13 · Proof gates
PreviousNext

The smallest integration to build

Give the specialist findings,
with bounded evidence

Proposed fixed read-only tools

list_security_findings
get_security_finding
get_security_evidence

Use the findings HTTP API through an authenticated adapter. Bound rows, bytes, field length, and time.

The evidence contract

  • Finding ID, status, and severity
  • Cluster and graph revision
  • Stable workload and resource identities
  • Evidence IDs and observation time
  • Explicit truncation and freshness

Deduplicate by finding and stable workload identity. Keep full-graph paging out of the chat context.

The supplied reasoning MCP server serves a saved immutable packet. It is not a continuously refreshed graph MCP server. The adapter above is proposed, not implemented.

10 / 13 · The kagent handoff
PreviousNext

Execution authority

Keep the approval and
execution identities explicit

  1. AgentShieldProvides evidence and a proposed action.
  2. kagentExplains the impact and prepares a bounded change proposal.
  3. Human reviewRecords approval for the exact reviewed change.
  4. Argo and FluxUse scoped workflow and reconciliation identities to deliver it.
  5. Traffic probesConfirm both deny and allow behavior, then test rollback.
The in-cluster chart disables AgentShield live remediation on its non-loopback listener. Local UI approval is not an enterprise identity or durable approval audit.
