Conceptual direction

The application-embedded concept

An application event can start or resume an investigation without waiting for a chat prompt.

EventA log, application event, trade event or database event supplies a signal.
DecisionA classifier or decision rule determines whether the signal needs an agent.
AdmissionCode applies thresholds, correlation and duplicate handling before dispatch.
Durable agentA new agent gets application context. A returning agent resumes its persisted incident context.

Target architecture with native POC

Substrate and incident context

The runtime restores execution state while the agent continues the incident workflow.

DefinitionAgent instructions identify the application, evidence sources and permitted workflow.
ExecutionSubstrate hosts isolated actors and restores their durable state.
ContinuitySession records and persisted application data retain the investigation and pending decisions.
KnowledgeConfigured skills and tools supply procedures. Their presence and loading need verification.
