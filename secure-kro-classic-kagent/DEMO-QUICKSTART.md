# DICE / UK8S — demo quickstart

1. Download the repository ZIP from https://github.com/davidmarkgardiner/kagent-work-bundles/archive/refs/heads/main.zip and extract it.
2. Open the `secure-kro-classic-kagent` folder. Keep its folders and files together.
3. Open `START-HERE.html` in Chrome or Edge. No Python, npm or cluster is needed.
4. Start **Story 1** for the product journey, then choose **Triage** and **SDLC** for Story 2.

Use **← / →** to navigate the animated chapters, **Replay / R** to replay, and **Notes / N** for presenter notes. **Repeat after** controls automatic replay without advancing slides. Click a component for source details. **Print all slides** prints the complete chapter or saves it as PDF; the review sheets also print to PDF.

The start page also opens the mock IDP, review sheets, resource and hardening explanations, desired state, and earlier architecture. The mock IDP accepts a form or customer YAML and simulates an API handoff. Location and custom IAM / Entra identity remain planned onboarding metadata.

Interactive flows are synthetic illustrations: they make no model calls or deployments. Dated lab receipts record earlier checks, not current runtime status. Supporting source references are copied into the bundle for offline review.

The main demos share red, white and black styling with light green takeaways. Older supporting references retain their original layouts; separate-workspace sources are explicitly marked when they are not included.
