Ready to present

Download and extract the complete folder, then open START-HERE.html in Chrome or Edge. The static presentations need no Python, npm or cluster. Keep the folder together so the local links work.

In the animated chapters, use ← / → to move, Replay or R to replay, and Notes or N for presenter notes. Print all slides exports the whole chapter; the review sheets also print to PDF.

The animated slides and mock IDP are synthetic illustrations. The separate live onboarding demo uses a local Python backend and an approved cluster; its buttons perform actual deployment, model and deletion requests when connected. Dated lab receipts describe earlier checks, not current runtime status. Location and custom IAM / Entra identity are planned onboarding metadata.
