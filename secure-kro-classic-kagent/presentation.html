02 / Platform reconciliation
KRO builds the boundary.
Security exists before customer access opens. The native Agent creates a normal Deployment and Service. Golden has a separate identity and listener; its successful Job unlocks the caller route.



Illustration only. This page never deploys resources or reads cluster status.




No JWT value is stored in the customer YAML. Golden receives a projected token with a dedicated audience. An authorized operator can mint a short-lived caller token for the terminal demonstration. ReferenceGrants are needed only for reviewed cross-namespace backend references.
