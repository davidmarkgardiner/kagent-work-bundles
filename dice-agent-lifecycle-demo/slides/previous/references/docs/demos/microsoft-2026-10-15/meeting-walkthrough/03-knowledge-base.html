Articles become a searchable index

Reviewed documentation remains the source of the answer.

Source articlesPlatform runbooks and knowledge articles live in Git.
Indexingdoc2vec splits articles into chunks and creates embeddings.
StorageThe local POC stores chunks and vectors in platform-kb.db.
Retrievalquerydoc exposes the index through MCP to the knowledge agent.

A question becomes a cited answer

The agent retrieves relevant passages before writing its response.

AskThe SRE asks how to investigate a platform condition.
SearchThe knowledge agent calls query_documentation for the platform corpus.
GroundRetrieved article passages supply the documented explanation or procedure.
AnswerThe agent cites source paths and reports gaps when the articles do not answer the question.

Article maintenance and access

The retrieval path depends on reviewed content and a current index.

Content updatesReview article changes in Git, then rebuild the index.
Index healthCheck embedding failures and the published corpus version.
AccessKeep the corpus and retrieval endpoint within the caller's approved data scope.
Knowledge gapsRecord missing or stale guidance for the documentation change workflow.

Speaker notes

The repo uses docs/platform-kb, doc2vec and querydoc. Upstream supports SQLite with sqlite-vec and Qdrant. This POC uses the SQLite database path. Here vector means semantic retrieval. It is separate from the Vector telemetry processor in the Kafka deck.

Speaker notes

The local prompt uses productName platform-kb, version current and dbName platform-kb.db. A similarity match does not prove that a runbook applies to the current cluster or software version. Check the article's scope before recommending an action.

Speaker notes

The POC refuses to publish a DB after embedding errors and keeps its indexer suspended by default. Its knowledge agent has read-only instructions. Per-document authorization is a production requirement to assess, not a feature proved by this POC.

  • Platform knowledge-base POC

Speaker notes

Current release notes explicitly describe the removal. Existing agents that relied on the bundled query_documentation tool need migration or separate wiring. Do not present the integration as automatically available in every kagent installation.
