The demonstration prompts

Lens. Investigate the reported latency in the approved namespace and workload. Ask the permitted telemetry, Kubernetes and incident specialists. Return one cited timeline, observations, uncertainty and a proposed next action. Keep the request read-only.

Gateway. Locate the routes used by the demo. Show accepted policy attachments, separate caller and child-agent authorization, selected MCP tools, model limits and correlated telemetry. The final deck provides the talking points.

Presentation controls and fallback

Each deck has slide selection, keyboard navigation, optional speaker notes and fullscreen. Browser Print creates a slide-by-slide PDF. The YAML reader preserves the comments beside their fields. The pack works directly from disk without a server or external assets.

If a live application is unavailable, continue with the deck, YAML and retained evidence links. The notes distinguish recorded lab results, prepared packages and future concepts.
