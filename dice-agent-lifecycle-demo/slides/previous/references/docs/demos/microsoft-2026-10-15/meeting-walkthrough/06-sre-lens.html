One conversation for the SRE

SRE Lens routes the question to the permitted specialists.

SREAsks a question in the Lens application.
Orchestration agentIdentifies the information needed and selects relevant agents.
SpecialistsInvestigate their own data or system through scoped tools.
ResponseThe orchestrator combines findings into one answer for discussion.

Routing by the question

The orchestrator chooses the specialist that owns the required evidence.

ServiceNow incidentAsk the incident specialist for the permitted incident record and timeline.
Cluster behaviorAsk Kubernetes and telemetry specialists for runtime observations.
GitLab workAsk the GitLab specialist for issue, MR or pipeline status.
Documented procedureAsk the knowledge specialist for the relevant article and citations.

Delegation keeps each permission boundary

A2A delegation and tool access have separate checks.

Application to agentThe caller needs the intended audience, identity and invocation role.
Agent to specialistThe destination permits the source namespace and agent relationship.
Specialist to MCPThe child agent uses the tool route's separate identity and authorization.
Tool to resourceThe adapter and destination permissions constrain resource access and writes.
