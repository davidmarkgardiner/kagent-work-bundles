# Presentation library

Open `index.html`. It links the new ten-slide terminal-first lifecycle deck and all top-level HTML presentation pages from the previously published DICE classic bundle. Their local HTML supporting-reference closure is copied into `previous/`, so the primary decks and their on-page source links travel with this folder. The two managed-Kubernetes presentations are included under `platform/`.

The new deck uses Left/Right or Page Up/Page Down, a notes toggle with N, and landscape printing. The earlier decks retain their existing controls. Simulations, historical receipts and proposed designs retain their original labels. The live frontend page needs its existing backend; the work bundle does not start one.

`SOURCE-MANIFEST.json` records the copied paths, hashes and source commit. The original source is https://github.com/davidmarkgardiner/kagent-work-bundles/tree/main/secure-kro-classic-kagent. No video, voice generation, controller installation or public upload is required to present these HTML slides.
