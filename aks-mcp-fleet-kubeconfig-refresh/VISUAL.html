One refresh · one Secret · fixed-target pairs

Refresh once. Prove everything. Publish atomically.

The MCP pods never modify or redirect their kubeconfig. A morning workflow validates the fleet, publishes one single-context key per alias, and rolls only the matching fixed-target shards.

01 · REGISTRY

Approved aliases

GitOps defines each AKS identity and a separate sanitized routing map for the agent.

02 · BUILD

Fresh candidate

Argo uses Workload Identity and an ephemeral volume. No existing file is merged in.

03 · PROVE

Every context

Exact aliases, exec auth, size, namespace reachability, and read-only access must all pass.

04 · PUBLISH

One Secret

Each alias becomes one single-context key. Changed hash triggers atomic replacement and shard rollouts.

05 · ROUTE

Authenticated target

Argo validates alias + namespace. Agent Gateway authenticates the agent, then routes to the MCP shard mounting only that alias's key.
