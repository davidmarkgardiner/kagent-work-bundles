# Add the source security audit work agent

## Outcome

Run an authorized source-only review against a pinned application revision using
real reconnaissance, hunters and independent verifiers. Keep scanner evidence,
source candidates and runtime blockers traceable. Optionally deploy the no-tool
kagent companion to review supplied evidence.

## Acceptance

- [ ] Import the complete bundle through the approved air-gap process; no public
      repo, package, skill or image fetches.
- [ ] Verify preinstalled tools, local target Git objects, internal model route and
      actual child delegation; missing prerequisites stop the run.
- [ ] Verify bundle and pinned upstream assets offline.
- [ ] Choose approved target, paths, full source ref, private output path and budget.
- [ ] Verify runner can isolate child contexts, select requested models and export
      actual terminal receipts; no silent single-agent fallback.
- [ ] Run request preflight and preserve clean/dirty source status.
- [ ] Perform real authorized source-only audit with upstream coverage rules.
- [ ] Supply redacted scanner evidence or explicitly mark each scan not run.
- [ ] Validate upstream findings/coverage and local delegation records; preserve
      INCOMPLETE on gaps. Independently inspect host traces, not just JSON shape.
- [ ] Review tenant read/write/delete/export authorization and session/auth trust
      where present in scope; report unavailable deployment/runtime facts.
- [ ] No target execution, installs, endpoint probes, source edits or publication.
- [ ] If deploying evidence-review companion, validate installed CRD/ModelConfig,
      readiness and A2A supplied-evidence smoke in the selected approved context.

## Proof still required in the workplace

A real target audit, actual cross-model traces, scan freshness, installed-cluster
readiness and evidence-review runtime. Offline fixtures demonstrate contract
behavior only. Any future executable validation adapter must separately prove
network/environment/filesystem/resource isolation and safe artifact promotion.
