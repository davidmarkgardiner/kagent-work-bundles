# Reviewed data-only content

These are the reviewed skill and knowledge-document files carried forward from the earlier secure-BYO demonstration. The standalone image packages their exact data; the runtime validates their approved hashes before use. No script in these packages becomes an execution tool.

The two package identities are `aks-known-issues` and `kb-aks-bootstrap`. The knowledge package demonstrates a known document with exact citations and release evidence. It does not supply embeddings, a vector search service or operational Azure access.

`recipe.json` retains the earlier native content provenance and recorded OCI identities. It is historical source provenance, not an instruction to install Substrate or proof of office content delivery. This standalone bundle does not need a native OCI-content cache. Office integration must preserve and verify its approved Skill/KnowledgeBase delivery contracts.

The AKS skill includes its upstream MIT license, provenance and original frontmatter. The knowledge reference retains its Microsoft source URL and review date. Its `AKS-KB-ORAS-212-R1` marker is demonstration evidence, not a production incident result.
