triage rollout

Sensor segregation

scope=system

System log + event Sensors route to system-agentic-triage, with its own rate limit and semaphore.

scope=application

Application log + event Sensors route to application-agentic-triage, with independent backend capacity.

Tier progression

Tier 1 — both lanes enabled; critical logs and critical Kubernetes events.
Tier 2 — both lanes enabled; priority/error logs and additional actionable events.
Tier 3 — both lanes enabled; broad warning/error/event review.

Promotion gate: verify Alloy has no queue-full errors, Vector produces to Kafka, and the scoped Sensor creates the correct workflow before moving up a tier.
