Give your agent a signal from every app.

Deploy Sentinel alongside your Kubernetes application. When it detects a problem, it sends a signal through Agent Gateway so an agent can investigate where it happened.

Run the Whisky demo

From first signal to follow-up

  1. Sentinel detectsA scanner runs alongside the app in its worker cluster.
  2. Agent Gateway receivesThe scanner sends an alert to the configured gateway endpoint.
  3. The agent investigatesIt connects back to the worker cluster and checks the affected workload with scoped tools.
  4. The team gets a resultRoute the investigation to GitLab, ServiceNow, or another configured endpoint.
