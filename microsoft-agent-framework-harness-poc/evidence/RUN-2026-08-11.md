## Compatibility findings

The installed Python SDK was `agent-framework-core==1.13.0` and
`agent-framework-openai==1.12.0`.

- The default `OpenAIChatClient` uses the OpenAI Responses API. The lab's
  Agent Gateway model route accepts Chat Completions, so the POC uses the
  framework-provided `OpenAIChatCompletionClient` instead.
- Harness tool-approval middleware requires an `AgentSession`; the POC creates
  the stable `maf-harness-poc` session before its approved call.
- The file-memory provider defaults to the current working directory. The POC
  explicitly roots it in the PVC to make the state durable under a read-only
  container filesystem.

These are integration/configuration facts, not evidence that Microsoft Agent
Framework replaces Argo Workflows or that a fully autonomous SDLC chain is
ready. The scope proven here is approval-gated Harness-to-kagent orchestration.
