Home-lab proof / bounded SDLC factory

Harness orchestrates; kagent specialists do the work.

A Microsoft Agent Framework Harness Agent holds approval and durable state, then hands an approved request through kagent A2A specialists. Every stage has a separate context and a persisted receipt.

Current truth: approval → kagent is live-proven. The expanded factory deployed five Ready specialists and completed plan/build/test handoffs. It is not accepted as a full autonomous SDLC proof because cancelled client Jobs left later kagent tasks running/queued.

State contract

Persistent: request, approval decision, Harness session memory, per-stage A2A receipts, factory stage artifacts.

References only: a production build should pass issue/branch/commit/MR IDs—not source blobs—between stages.

Fail closed: absent artifact, non-terminal response, non-PASS evaluation, or timeout ends the run at its last durable stage.

Why the full-chain badge is intentionally absent

Deleting the caller Job did not reliably cancel in-flight kagent A2A tasks. This makes one long controller-mediated chain unsuitable as the production execution substrate today. The durable design should put each stage in a short Argo Workflow task (or equivalent), wait for a terminal receipt, and resume Harness state from the PVC/store for the next stage.
