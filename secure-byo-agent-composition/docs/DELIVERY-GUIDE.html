Rehearse the whole story.

Use the final delivered revision and a dedicated approved POC scope. The run sheet targets 8 to 12 minutes. Do not show tokens or call saved receipts fresh execution.

  1. 1. Explain the boundary

    Existing operator or approved KRO profile, runtime path, owner authority and platform prerequisites

    Retain: Exact revision/profile and a clear list of shared versus dedicated resources

  2. 2. Apply one request

    Submit the reviewed owner YAML under the restricted owner identity

    Retain: Actual accepted request and the generated resource graph, routes and grants

  3. 3. Use the agent

    Invoke with the approved identity and supplied synthetic documentation case

    Retain: Fresh task or completed Job, actual skill/knowledge calls, approved model and MCP result, current content pins

  4. 4. Reject unsafe changes

    Present an admitted control, then forbidden binding/privilege and copied-identity cases

    Retain: Actual policy/rule denial and a matching allowed control; no schema-only or RBAC-only failure presented as Kyverno proof

  5. 5. Deny the wrong caller and direct path

    Wrong principal or audience, forbidden operation and bypass attempts

    Retain: Actual denial plus backend witness; reachable approved path as a positive control

  6. 6. Revoke and recover

    Revoke current approval, deny fresh authority, explain already-dispatched work, then independently restore approval

    Retain: Timestamped counters, no returned protected result, observed settlement bound and fresh successful recovery

  7. 7. Retire and recreate

    Remove the dedicated request, retain shared prerequisites, and reject stale same-name approval

    Retain: Complete owned inventory cleanup and new UIDs; fresh approval and fresh acceptance after recreation

  8. 8. Compare and close

    Explain KRO versus the existing HostedAgent extension and leave the agreed stable state

    Retain: Rehearsal receipt, exact tested scope, limits, and operator handoff

After recreation, obtain fresh independent approval and repeat acceptance. Leave the agreed stable state. If rehearsal fails, retain the receipt, fix the cause, and repeat the full rehearsal.
